## 📖 Usage Examples

### Execute via HTTP

```bash
curl -X POST https://api.meauxbility.org/godmode/api/execute \
  -H "Content-Type: application/json" \
  -d '{
    "command": "GH",
    "payload": {}
  }'
```

### Execute via WebSocket

```javascript
const ws = new WebSocket('wss://api.meauxbility.org/godmode');

ws.onopen = () => {
  ws.send(JSON.stringify({
    type: 'EXECUTE_COMMAND',
    command: 'FA',
    payload: {
      name: 'my-app',
      framework: 'next'
    }
  }));
};

ws.onmessage = (event) => {
  const result = JSON.parse(event.data);
  console.log('Result:', result);
};
```

### Execute via Email (#MEAUXWORK)

```
Subject: Create new landing page

Hey team,

Please create a landing page for our Q4 campaign.

#MEAUXWORK /LP name="q4-campaign" theme="dark"

Thanks!
```
